# API Reference

Every public type of PlayForge: its runtime, the Creator Lab, its editor and its test kit, read from the comments in its
source. Each type's page says which guide sections name it, or which guide covers its area, and the guides link each
type they name in code to its page.

The contents group the types by area, as the package's folders do. Everything in the runtime is in the namespace
`FarEmerald.PlayForge`, the Creator Lab's in `FarEmerald.PlayForge.Lab`, the editor's in `FarEmerald.PlayForge.Editor`
and the test kit's in `FarEmerald.PlayForge.Testing`. Search finds a type by name.
